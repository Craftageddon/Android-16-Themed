# Full retained-library scope register

Every cached source record was accounted for and valid records were SHA-256 checked. This is a rule-assisted inventory, not a claim that every source was visually reviewed or redrawn. `all-retained-files.csv` records every file and provenance, `family-candidates.csv` proposes normalized family groupings and source candidates, and `roadmap-source-coverage.csv` retains every one of the 103 work packages with matches or an explicit unresolved state. The proposed source ranking favors SVG and RC2 sources; human visual review can override it. Preserve all historical sources.

The earlier catalog also contains website/brand references, sounds, fonts, exports, masks and captures. Do not describe its total file count as the number of independent Android visual assets. One invalid zero-byte record is retained as evidence and excluded from valid assets.
