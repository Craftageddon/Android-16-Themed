# Iteration 03 — Ember Steel pilot

18 original editable component specimens. The everyday material uses faceted dark steel, recessed wells, structural copper and discontinuous ember channels. Detailed and compact symbols intentionally differ.

- `masters/`: Inkscape-compatible layered SVGs; emission layers hidden by default.
- `layers/`: individual cold, seam, core and symbol layers. White masks contain alpha, never baked orange. Empty mask layers are intentional for compact battery.
- `exports/`: transparent 1x and 2x PNG cold/symbol layers and neutral masks. State PNGs are review-only.
- `previews/`: contact/state sheets; labels and values are illustrative live-content examples.
- `components.json`, `tokens.json`: geometry and state contract.

The exported frame sizes are fixed pilot specimens. Do not stretch textured bevels; use native procedural corners or explicitly authored nine-patches in a later integration pass. `symbol` is a separate semantic layer. Keyboard, gamepad focus, state handling, hardware and screen routing are design handoffs until integrated and tested.

All 103 roadmap packages remain tracked separately. This checkpoint does not complete the ROM or whole-library rework. No device was modified or flashed.
