# Iteration 04 — scope register and core component system

46 original component variants expand ES-011..024 and begin the keyboard/controller cap families. Every master is layered cold/seam/core/symbol with no text. Labels in review images are illustrative live content. Eight state previews include hover, focus, selection, press, disabled and reduced motion. PNG layers are supplied at 1x/2x in complete-assets.zip. Native hit targets require at least 48dp padding. Fixed-size decorated assets must not be stretched blindly.

The source-register folder accounts for all retained cached files and proposes family mappings; it does not claim full visual approval. Frame material and composition are still subject to target-device and user acceptance. No native SystemUI integration or hardware change is included.
