# Native lab review

This checkpoint advances from compiled assets to an independently built Android application. Source inspection confirms five separate drawable layers, live Button/EditText/TextView content, app-local input translation, explicit source display reporting and no privileged permissions or hardware writes.

The resource pack and Java build passed twice in separate output folders; executable/resource payloads matched. Native runtime behavior has not been observed. No screenshot is represented as an installed application capture. The iteration 07 contact sheet remains a desktop asset preview.

The lab intentionally keeps every illumination state static. Width/text/RTL toggles are review tools; they do not establish complete localization or accessibility acceptance. Pending target tests include large-text wrapping, input focus and selection during press, screen rotation, real insets, secondary displays, controller disconnect, cold/disabled states and memory/frame timing. Keep those results separate from the existing compile/package evidence.
