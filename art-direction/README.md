# Ember Steel direction

The visual anchors are the user's earlier Craftageddon steel button socket, notification frame and connectivity sheet. The reference copies were inspected on 2026-10-20. The authored geometry is new and the generated study uses those images only for appearance guidance.

- Dark gunmetal occupies most of a control; copper marks structural joints.
- Bevels and angled planes create thickness without filling the reading area.
- Red-orange light stays inside narrow channels with tiny hot cores.
- Normal idle retains restrained warmth. Cold inspection remains available.
- Compact symbols trade texture and ornament for recognizable contours.

`ember-steel-study.png` was generated with the built-in image-generation tool. It is a raster reference board, not a source atlas. Its A/B/X/Y layout is illustrative and does not assert Thor's hardware mapping.

The full generation prompt is in `material-study-prompt.txt`. No API keys or fallback API generation were used.
