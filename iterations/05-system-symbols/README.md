# Iteration 05 — system symbol families

136 named symbols, each with separately authored compact and detailed optical treatment (272 masters). Includes settings categories; battery/Wi-Fi/cellular state families; connectivity; privacy; audio; transfer; input; display routing; power; fan/performance; and common actions. This is defined-family coverage, not an installed-app icon collection.

Every original SVG separates cold/seam/core/symbol. Transparent PNG layers are supplied at 1x/2x. Status lighting is steady; focus belongs to the interactive container, not to the status glyph. Native XML exports contain the compact semantic geometry only. They do not reproduce detailed gradient steel, and compilation is not native integration. No unsupported device feature is implied by the availability of an icon.
