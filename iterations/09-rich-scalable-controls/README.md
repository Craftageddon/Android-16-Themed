# Iteration 09 — rich forged-steel scalable controls

The four scalable control families now follow the heavier notification/tile art: original pointed steel fittings, physically modeled chipped bevels, dark structural copper and recessed light channels. The button, field, panel and notification frames each have seven independent layers: cold, reflection, spill, seam, core, focus and symbol. Four Android densities give 112 real nine-patch configurations and 28 logical drawables.

The 2172 × 724 cold source is original built-in image generation, using the earlier cold tile/notification as style references. Its original bytes and alpha are preserved in source/cold-frame.png. Editable SVG composition fixes the photographic corners in place, selects constant rail cross-sections and supplies a quiet live-content well. No orange emission is written into cold art. Keep source/ beside masters/ and layers/ when opening SVGs in Inkscape.

The selected/pressed preview images are rendered from the actual exported layers. Selected adds an ember seam, warm core, restrained reflected light and a geometric diamond; press raises core/spill/reflection intensity. Focus has its own neutral corner brackets. Selection and focus must remain independent in the native owner, including during press. Disabled suppresses every light/selection/focus mask. The reduced-motion snapshot is static. Preview labels are illustrative and are not in the asset masters.

Each density's top/left metadata marks only constant bands. Bottom/right metadata specifies content padding. Declared minimum dimensions preserve the decorated caps. Rich texture is retained on fixed material pieces; uniform cross-sections allow the rails to resize without stretching decorative chips. The original thin iteration 07 and fixed-aspect iteration 06 remain archived for comparison.

Checks: 112 metadata/pixel exports; 96 neutral mask configurations; 224 constant-band checks; 1344 fixed-corner comparisons; cold source hash and no light filter in cold groups; SVG/PNG parse; distinct cold/idle/selected/pressed/disabled snapshots; Android compile/link of all 112 configurations into 28 drawables. V3/device rendering, small-screen density budgets, accessibility, exact Thor layout and performance remain pending.

**Material Lab 0.1.0 remains unchanged and still shows iteration 07.** This is a new asset/render checkpoint, not an updated APK or installed theme. A native renderer must consume the extra reflection and spill layers and compare its blending against these previews. There is no ROM or hardware change.
