Original PNG bytes are preserved. Named Inkscape layers separate the cold raster, neutral seam mask, neutral hot-core mask and live symbol ownership. Keep each cold PNG beside its SVG master.

The screen SVGs embed the cold image for portability; material SVGs link the adjacent cold PNG.

These substantial decorative frames are fixed-aspect design candidates, not stretchable nine-patches or compact production layouts.
